# Summa Theologica Repository

This repository contains the complete Summa Theologica, organized with each article in its own individual text file for easy querying and analysis.

## Structure

The Summa is organized into three main parts:

1. **Prima Pars (I_Pars)** - On God
2. **Prima Secundae (II_Pars)** - On the Things that Conduce to the Happiness of Man
3. **Secunda Secundae (III_Pars)** - On the Things that Conduce to the Happiness of Man

## File Organization

Each article is contained in its own file with a naming convention:
`article_{number}_{reference}.txt`

For example:
- `article_001_I,_Q._49,_Art._2.txt`
- `article_002_II-II,_Q._1,_Art._1.txt`
- `article_003_II-II,_Q._1,_Art._2.txt`

## Usage for AI Analysis

These files can be used to:
1. Query individual articles directly
2. Create RAG (Retrieval-Augmented Generation) systems
3. Perform deep analysis of specific theological points
4. Compare different perspectives within the Summa

## Note on Content

All content is from the Project Gutenberg edition, translated by the Fathers of the English Dominican Province. This is a public domain work containing the complete Summa Theologica in English translation.
